# Show-strukturer og Time-planer

## Den Perfekte Time-planen

```
06:00 - HARD START
├── Nyheter (2 min)
├── Trafikk (1 min)
├── Vær (30 sek)
└── Teaser: "I dag skal vi..." (30 sek)

06:05 - SEGMENT 1 (10 min)
├── Hook (30 sek)
├── Hovedinnhold (7 min)
├── Interaksjon (2 min)
└── Reset/Tease neste (30 sek)

06:15 - MUSIKK BLOKK (15 min)
├── 3-4 sanger
├── Quick teases mellom
└── Station ID

06:30 - SEGMENT 2 (10 min)
[...pattern repeats...]

07:00 - PRIME TIME START
├── Større segmenter
├── Mer interaksjon
└── Høyere energi

09:00 - WIND DOWN
├── Mykere innhold
├── Forberedelse til dag
└── "Takk for i dag"
```

## Segment-arkitektur

### The 10-Minute Rule
Hvert segment maks 10 minutter:
- 0:00-0:30: Hook (få oppmerksomhet)
- 0:30-2:00: Setup (etabler kontekst)
- 2:00-7:00: Meat (hovedinnhold)
- 7:00-9:00: Payoff (konklusjon/vits)
- 9:00-10:00: Reset (tease neste)

### The Clock Face Method
Del timen i "kvarter":
- :00-:15: Start energisk
- :15-:30: Bygg momentum
- :30-:45: Peak content
- :45-:00: Avslutt sterkt

Hver kvartal = ny sjanse til å fange lyttere

### The Tease-Deliver-Reset Pattern

**Tease (10-15 sek):**
- "Om litt skal vi..."
- "Du vil ikke tro..."
- "Hør hva som skjedde..."

**Deliver (2-8 min):**
- Lever det du lovet
- Hold energien oppe
- Engasjer lytteren

**Reset (10-15 sek):**
- "Nå skal vi..."
- "Men først..."
- "Vi kommer tilbake til..."

## Formater for ulike segment-typer

### Nyhetssegment (3-5 min)
```
0:00-0:15: "Her er nyhetene"
0:15-1:00: Topp-sak
1:00-2:00: Sak 2
2:00-3:00: Sak 3 + lett vri
3:00-4:00: Sport/vær
4:00-5:00: Utro + tease
```

### Intervju-segment (8-12 min)
```
0:00-0:30: Intro av gjest
0:30-2:00: Warm-up, personlig
2:00-5:00: Hovedtema 1
5:00-7:00: Hovedtema 2
7:00-9:00: Quick-fire spørsmål
9:00-10:00: Promo av gjestens prosjekt
10:00-12:00: Avslutning, takk
```

### Telefon-segment (5-8 min)
```
0:00-0:30: Forklar konsept
0:30-1:00: Første lytter på
1:00-4:00: Samtale, eskalering
4:00-5:00: Konklusjon/premie
5:00-6:00: Neste lytter (valgfritt)
6:00-8:00: Oppsummering
```

### Musikk-segment (15-20 min)
```
0:00-0:15: Intro, "her kommer..."
0:15-4:00: Sang 1
4:00-4:30: Quick chat/tease
4:30-8:00: Sang 2
8:00-8:30: Quick chat/tease
8:30-12:00: Sang 3
12:00-12:30: Quick chat/tease
12:30-16:00: Sang 4
16:00-20:00: Outro, tease neste
```

## Avanserte strukturer

### The Narrative Arc (20-30 min spesial)
```
Act 1 (5-7 min): Setup
├── Introduksjon av tema
├── Karakterer etableres
└── "Noe kommer til å skje"

Act 2 (10-15 min): Confrontation
├── Konflikt bygger seg opp
├── Tension øker
├── Climax nærmer seg

Act 3 (5-8 min): Resolution
├── Climax
├── Konsekvenser
└── "The moral of the story"
```

### The Magazine Format (60 min)
```
Segment 1 (10 min): Hard news/feature
Segment 2 (10 min): Interview
Segment 3 (10 min): Phone-in/interaction
Segment 4 (10 min): Entertainment
Segment 5 (10 min): Music feature
Segment 6 (10 min): Wrap-up, previews
```

### The Rolling Format ( kontinuerlig)
- Ingen faste segmenter
- Flytende overganger
- "Stream of consciousness"
- Krever svært dyktige hosts
- Eksempel: Howard Stern

## Timing-prinsipper

### The 3-Second Rule
- Lytteren bestemmer seg på 3 sekunder
- Start hvert segment sterkt
- Aldri "soft open"

### The 8-Minute Rule
- Maks 8 minutter før reset
- Lytteren "tuner ut" etter 8 min
- Reset = ny sjanse

### The 15-Minute Rule
- Hver 15. minutt = nytt "kvarter"
- Lyttere sjekker inn på klokkeslett
- :00, :15, :30, :45 = viktige punkter

### The 30-Minute Rule
- Større reset hver halvtime
- Ny energi, nytt fokus
- "Halvtimen som gikk..."

## Praktiske tips

### Planlegging
1. Lag en "clock" - visuell time-plan
2. Fargkod segment-typer
3. Marker "must-listen" moments
4. Ha backup-planer

### Fleksibilitet
- Klokken er viktig, men ikke slavebundet
- Hvis noe er bra - kjør lenger
- Hvis noe dør - avbryt tidlig
- Les lytteren
