## Norske Formater

### Morgenshow (06:00-10:00)
**Struktur:**
- 06:00-06:15: Hard start, nyheter, trafikk
- 06:15-07:00: Myk landing, vær, prat
- 07:00-09:00: Prime time - topp underholdning
- 09:00-10:00: Utgang, forberedelse til dag

**Kjente show:**
- NRJ Morgen - Ungt, energisk, pranks
- P3 Morgen - Kultur, musikk, samfunn
- Radio Norge Morgen - Voksent, nyheter, debatt

**Benchmarks:**
- "Telefonscam" - Klassisk, alltid populær
- "Morgenhilsen" - Personlig hilsen til lyttere
- "Trafikk-trivia" - Quiz mens du sitter i kø

### Ettermiddag (14:00-18:00)
**Struktur:**
- 14:00-15:00: Myk start, musikk, prat
- 15:00-16:00: Skole-slutt, yngre lyttere
- 16:00-18:00: Rush hour - trafikk, nyheter

**Kjente show:**
- P3 Ettermiddag - Musikk, trender
- Radio 1 Ettermiddag - Voksen, livsstil

### Kveld (18:00-24:00)
**Struktur:**
- 18:00-20:00: Avslappende, middagstid
- 20:00-22:00: Temakveld, dypere innhold
- 22:00-24:00: Natt, intime samtaler

## Segment-strukturer

### The Classic Interview
```
0:00-0:30  - Intro, cred
0:30-2:00  - Warm-up, personlig
2:00-5:00  - Hovedtema
5:00-7:00  - Avslutning, promo
```

### The Phone-in
```
0:00-0:15  - Problem presenteres
0:15-1:00  - Første lytter
1:00-3:00  - Diskusjon
3:00-4:00  - Konklusjon
```

### The Game/Quiz
```
0:00-0:30  - Regler forklares
0:30-1:00  - Deltaker intro
1:00-4:00  - Spill gjennomføres
4:00-5:00  - Vinner kåres, premie
```

### The Prank
```
0:00-0:20  - Setup forklares
0:20-1:00  - Prank utføres
1:00-4:00  - Reaksjon, eskalering
4:00-5:00  - Reveal, aftermath
```

## Formel for suksess

1. **Konsistens** - Samme tid, samme sted
2. **Personlighet** - Unik stemme, ikke generisk
3. **Interaksjon** - Lytteren må føle seg sett
4. **Kvalitet** - God lyd, god produksjon
5. **Timing** - Perfekt komisk timing, pauser
